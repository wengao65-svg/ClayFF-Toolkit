# Security policy

## Supported versions

Security fixes are provided for the latest released version. Older versions
may receive a fix when the same change can be applied safely.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose users or
their data. Use GitHub's private vulnerability reporting feature for this
repository. If that feature is unavailable, contact the repository owner
privately through the contact information on their GitHub profile.

Include the affected version, platform, reproduction steps, impact, and any
suggested mitigation. Please allow the maintainers reasonable time to confirm
and address the report before public disclosure.

ClayFF-Toolkit processes scientific structure files supplied by users. Treat
files from untrusted sources cautiously and avoid running the GUI or CLI with
unnecessary privileges.
